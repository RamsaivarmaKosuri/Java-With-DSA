# Assignment Operators

Assignment operators are used to assign values to variables.

## Types of Assignment Operators

```text
=
+=
-=
*=
/=
%=
```

---

## 1. Assignment Operator `=`

Used to assign value.

Example:

```java
int a = 10;
```

Here:

```text
10 is assigned to a
```

---

## 2. Add and Assign `+=`

Example:

```java
int a = 10;

a += 5;

System.out.println(a);
```

## Output

```text
15
```

### Understanding

```java
a += 5
```

means:

```java
a = a + 5
```

---

## 3. Subtract and Assign `-=`

Example:

```java
int a = 10;

a -= 3;

System.out.println(a);
```

## Output

```text
7
```

### Understanding

```java
a -= 3
```

means:

```java
a = a - 3
```

---

## 4. Multiply and Assign `*=`

Example:

```java

System.out.println(a);
```

## Output

```text

```

### Understanding

```java
a *= 2
```

means:

```java
a = a * 2
```

---

## 5. Divide and Assign `/=`

```java

```

## Output

## 6. Modulus and Assign `%=`

Example:

```java
int a = 10;

a %= 3;

System.out.println(a);
```

## Output

```text
1
```

### Understanding

```java

```

means:

```java

```

---

## Important Note

Assignment operators help write code in a shorter way.

Example:

Instead of:

```java
a = a + 5;
```

we write:

```java
a += 5;
```
