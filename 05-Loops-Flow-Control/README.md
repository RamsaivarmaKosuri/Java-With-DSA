# Loops (Flow Control)

Loops are used to execute a block of code repeatedly.

Instead of writing the same code many times, we use loops.

Loops help in:

- Reducing code repetition
- Saving time
- Writing cleaner code
- Improving efficiency

---

## Types of Loops in Java

1. While Loop
2. For Loop
3. Do While Loop

## Key Takeaways

- Loops help repeat code efficiently
- `while` loop runs until condition becomes false
- `for` loop is useful when number of iterations is known
- `do while` loop executes at least one time
- `break` stops the loop immediately
- `continue` skips current iteration
