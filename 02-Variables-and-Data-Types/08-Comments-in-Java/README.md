# Comments in Java

## What are Comments?

Comments are parts of code that **do not execute**.

Compiler ignores comments.

They are used to explain logic, code, or information for humans to read.

## Why Use Comments?

- To explain logic
- To make code easier to understand
- To remember important points

---

## Types of Comments

### 1. Single Line Comment

Used for writing one line comment.

Syntax:

```java
// This is a single line comment
```

Example:

```java
public class JavaBasics {
    public static void main(String[] args) {

        // printing hello
        System.out.println("Hello");

    }
}
```

---

### 2. Multi Line Comment

Used for writing multiple line comments.

Syntax:

```java
/*
This is a
multi line comment
*/
```

Example:

```java
public class JavaBasics {
    public static void main(String[] args) {

        /*
        This program
        prints Hello
        */

        System.out.println("Hello");

    }
}
```

## Important Note

Comments are only for humans.

Compiler ignores them.
