# Boilerplate Code in Java

## What is Boilerplate Code?

Boilerplate code is the basic structure needed to run a Java program.

Every Java program starts with this structure.

## Example

```java
public class JavaBasics {
    public static void main(String args[]) {

    }
}
```

## Understanding the Code

### `public class JavaBasics`

- `class` is used to create a class.
- `JavaBasics` is the class name.
- File name and class name should be the same.

Example:

```text
JavaBasics.java
```

### `public static void main(String args[])`

This is the **main method**.

Java program execution starts from here.

## Important Note

The file name and class name must be the same in Java.
