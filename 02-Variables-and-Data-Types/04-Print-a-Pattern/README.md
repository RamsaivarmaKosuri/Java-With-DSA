# Print a Pattern

Printing patterns helps us understand output formatting in Java.

## Example Program

```java
public class JavaBasics {
    public static void main(String[] args) {

        System.out.println("****");
        System.out.println("***");
        System.out.println("**");
        System.out.println("*");

    }
}
```

## Output

```text
****
***
**
*
```

## Understanding

- `println()` prints output and moves to next line.
- Every statement prints one row.

Patterns help improve logic building and problem-solving.
