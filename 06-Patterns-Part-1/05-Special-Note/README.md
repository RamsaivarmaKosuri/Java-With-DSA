## Final Advice

Do not try to:

```text
memorize patterns
```

Instead:

```text
understand the logic
```

Ask yourself:

```text
1. How many lines?
2. How many times to print?
3. What to print?
```

If you understand these:

```text
you can solve most basic patterns
```

---

## Golden Rule for Patterns

```text
Outer Loop → Number of Lines

Inner Loop → Work inside each Line

What to Print → Pattern Logic
```
