# Functions & Methods

Functions are used to:

```text
reuse code
```

Instead of writing the same code multiple times, we can place it inside a:

```text
function
```

and call it whenever needed.

---

## Why Learn Functions?

Functions help in:

- Code Reusability
- Cleaner Code
- Better Organization
- Easier Debugging
- Reduced Repetition

Functions are heavily used in:

- Placements
- DSA
- Real Projects
- Interviews
