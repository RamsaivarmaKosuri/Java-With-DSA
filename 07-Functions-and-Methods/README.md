# Functions & Methods

Functions are used to:

- Reuse Code

Instead of writing the same code multiple times, we can place it inside a:

```text
function
```

and call it whenever needed.

---

## Why Learn Functions?

Functions help in:

- Code Reusability
- Cleaner Code
- Better Organization
- Easier Debugging
- Reduced Repetition

Functions are heavily used in:

- Placements
- DSA
- Real Projects
- Interviews

## Key Takeaways

- Functions reduce code repetition.
- Functions make code reusable.
- Methods are functions inside classes.
- Parameters receive values.
- Arguments send values.
- Call Stack manages function execution.
- Java uses Call by Value.
- Functions can call other functions.
- Function Overloading allows multiple methods with the same name.
- Overloading can be achieved using parameters or data types.
- Prime numbers can be efficiently checked using `Math.sqrt(n)`.
- Reusable functions make programs cleaner and easier to maintain.
