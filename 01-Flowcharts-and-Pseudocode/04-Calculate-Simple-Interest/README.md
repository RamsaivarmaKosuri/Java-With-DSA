# Calculate Simple Interest

## Problem Statement

Calculate Simple Interest using principal amount, rate of interest, and time.

## Formula

SI = (P × R × T) / 100

Where:
- P = Principal Amount
- R = Rate of Interest
- T = Time

## Flow

1. Start
2. Input Principal, Rate, and Time
3. Calculate SI
4. Display SI
5. End

## Pseudocode

START

INPUT P, R, T

SI = (P × R × T) / 100

DISPLAY SI

END
